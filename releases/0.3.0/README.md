# 0.3.0 test build

[Download the Forge 1.20.1 JAR](cozy-kitchens-forge-1.20.1-0.3.0.jar?raw=true).

Blue sink water, complete solid faucets, enclosed corner boxes, separate left/right cabinet doors, corrected counter/oven surfaces, and smooth ceramic appliances in the existing colors. Refrigerator caps and stacking bands match their finish.

All survival recipes, registry IDs, native inventories/upgrades and the accepted cabinet artwork are retained. Replace the previous Cozy Kitchens JAR; use the same version on clients and servers. Requires Cooking for Blockheads 16.0.15 and Balm 7.3.43+ (7.x) on Minecraft 1.20.1 / Forge.
