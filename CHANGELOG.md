# Changelog

## 0.2.1

- Gold faucets for spruce, jungle, dark oak, mangrove, cherry, and crimson sinks.
- Black faucets for oak, birch, acacia, bamboo, warped, and pale oak sinks.
- Original pale oak side and top/bottom textures matching the lattice doors.
- Existing geometry, cabinet fronts, appliances, and production Java classes preserved from 0.2.0.

## 0.2.0

- Distinct Farmer's Delight cabinetry for eleven woods, plus original pale oak lattice fronts.
- Recessed sink basins, fitted native water models, white ceramic faucets, and corrected catalog depth rendering.
- Approved oven, refrigerator, toaster, and quartz countertop assets preserved.

## 0.1.0

- Initial Forge 1.20.1 / Cooking for Blockheads 16.0.15 add-on.
- Six furnishings in twelve woods, including optional Backport pale oak.
- Ovens, refrigerators, and toasters in ivory, sage, blush, and charcoal.
- Native kitchen connections, block entities, upgrades, inventories, and animated models.

## Repository setup

- Imported the 0.2.1 source and unchanged test-build JAR.
- Added the catalog, installation guide, attribution, contribution guidance, and issue forms.
- Added a production-build and base/Backport GameTest workflow.

The repository setup does not change the mod's version or runtime behavior.
